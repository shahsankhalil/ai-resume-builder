# AI Resume Builder

An AI-powered resume generator built with vanilla HTML, CSS, and JavaScript.
---

## Live Demo

> [**Try it here →**](https://shahsankhalil.github.io/ai-resume-builder)

---

## Features

- **AI-generated content** — Claude writes your resume in a professional tone using your raw details
- **ATS-friendly format** — structured output that passes applicant tracking systems
- **One-click copy** — copy your resume to clipboard instantly
- **No backend needed** — runs entirely in the browser
- **Mobile responsive** — works on all screen sizes

## ⚙️ Setup & Usage

### Run locally (no setup needed)

1. Clone this repo:
```bash
   git clone https://github.com/shahsankhalil/ai-resume-builder.git
```
2. Open `index.html` in your browser — that's it.

---

## 💡 How It Works

1. User fills in personal info, education, skills, and projects
2. The app builds a detailed prompt with all the information
3. The prompt is sent to the Claude API
4. Claude returns a polished, professional resume
5. The resume is displayed and ready to copy
